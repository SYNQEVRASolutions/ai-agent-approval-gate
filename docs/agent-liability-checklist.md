# AI Agent Liability Checklist

Use this before an agent is allowed to act on production equipment.

1. **Name the accountable person.** Every high risk action class has a named owner, not a team inbox.
2. **Write down the blast radius.** What is the worst outcome of this action, and who is affected?
3. **Prove the baseline first.** Two weeks of read-only data per load level and per shift, before any action.
4. **Make every automated action reversible.** If it cannot be undone, it stays manual.
5. **Set the caps before you need them.** Actions per hour, spend ceiling, and the number of assets touched.
6. **Log the reasoning, not only the result.** Which value moved, when, by how much, expected effect.
7. **Decide the escalation path.** When a cap is hit, the agent stops and escalates; it never improvises.
8. **Keep an offline runbook.** If the agent is down, the site still runs on the old procedure.
9. **Test the denial.** Force a blocked action and confirm the alert reaches a human in under five minutes.
10. **Review the audit trail weekly.** False positive rate, alarm to decision time, mean time to repair.
